# anthropic

A simple Python chatbot using the [Anthropic](https://www.anthropic.com/) API (Claude).

## Setup

1. Clone the repo:
   ```bash
   git clone https://github.com/BeingArindam/anthropic.git
   cd anthropic
   ```

2. Install dependencies:
   ```bash
   pip install anthropic python-dotenv
   ```

3. Create a `.env` file with your API key:
   ```
   ANTHROPIC_API_KEY=your_api_key_here
   ```

## Usage

```bash
python main.py
```
